# Demo script — 30–45 seconds

No voiceover is required; the motion carries it. If you record with voice, use the
lines in quotes.

| Time | Shot | Action |
|---|---|---|
| 0:00 | Title + board | Land on the page. "Two players, nine squares." |
| 0:05 | Board | Hover a card so the ghost mark and spotlight appear. |
| 0:08 | A1 → B1 → A2 | Play three moves; show the pin, the X ink, and the monocle. |
| 0:14 | Finish at A3 | Let the red yarn draw, the CASE CLOSED label land, and the flash fade. |
| 0:22 | Result bar | "The winning line is red yarn." Pause on CROSS WINS. |
| 0:27 | New Game | Click it. Show the empty board and the score still at 01. |
| 0:33 | Keyboard | Arrow to a cell, press Enter. Show the focus ring and the turn change. |
| 0:38 | Mobile | Cut to the 390px view; scroll the board and scoreboard. |
| 0:43 | Repo | End on the README or the live URL. |
