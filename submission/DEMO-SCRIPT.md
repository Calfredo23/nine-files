# Demo script — 30–45 seconds

No voiceover is required; the motion carries it. If recording with voice, use the
lines in quotes.

| Time | Shot | Action |
|---|---|---|
| 0:00 | Title + board | Land on the page. "Two detectives. Nine clues." |
| 0:05 | Board | Hover a card so the ghost mark and spotlight appear. |
| 0:08 | A1 → B1 → A2 | File three clues; show the pin, the X ink, and the monocle. |
| 0:14 | Finish at A3 | Let the red yarn draw, the CASE CLOSED label slam, and the flash land. |
| 0:22 | Result bar | "The winning line is literal red yarn." Pause on CROSS WINS. |
| 0:27 | New Game | Click it. Show the empty board and the ledger still at 01. |
| 0:33 | Keyboard | Arrow to a cell, press Enter. Show the focus ring and the turn change. |
| 0:38 | Mobile | Cut to the 390px view; scroll the board and ledger. |
| 0:43 | Repo | End on the README or the live URL. |
