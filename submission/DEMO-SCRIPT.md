# Demo script — 30–45 seconds

No voiceover is required; the motion carries it. If you record with voice, use the
lines in quotes.

| Time | Shot | Action |
|---|---|---|
| 0:00 | Title + board | Land on the page. "Two players, nine squares." |
| 0:04 | Captain | Show Capt. Hale's note; pause on the grade label. |
| 0:07 | Board | Hover a card so the ghost mark and spotlight appear. |
| 0:09 | A1 → B1 → A2 | Play three moves; the captain's note and grade change after each. |
| 0:15 | Finish at A3 | Let the red yarn draw, the CASE CLOSED label land, and the flash fade. |
| 0:23 | Result + captain | "The winning line is red yarn." Pause on CROSS WINS and the final note. |
| 0:28 | New Game | Click it. Show the empty board and the score still at 01. |
| 0:34 | Keyboard | Arrow to a cell, press Enter. Show the focus ring and the turn change. |
| 0:39 | Mobile | Cut to the 390px view; scroll the board and scoreboard. |
| 0:44 | Repo | End on the README or the live URL. |
