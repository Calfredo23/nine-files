# Demo script — 30–45 seconds

No voiceover is required; the motion carries it. If you record with voice, use the
lines in quotes.

| Time | Shot | Action |
|---|---|---|
| 0:00 | Briefing | Land on the page. "Capt. Hale has the case." Let the three beats play, then **BEGIN THE CASE**. |
| 0:08 | Title + board | "Two players, nine squares. New Game is in the top-right panel." |
| 0:12 | Captain | Show Capt. Hale's note; pause on the grade label. |
| 0:15 | Board | Hover a card so the ghost mark and spotlight appear. |
| 0:17 | A1 → B1 → A2 | Play three moves; the captain's note and grade change after each. |
| 0:23 | Finish at A3 | Let the red yarn draw, the CASE CLOSED label land, and the flash fade. |
| 0:31 | Result + captain | "The winning line is red yarn." Pause on CROSS WINS and the final note. |
| 0:36 | Match history | Open **MATCH HISTORY** in the CASE CONTROL panel; show the saved result. |
| 0:41 | New Game | Click it. Show the empty board and the score/history kept. |
| 0:46 | Keyboard | Arrow to a cell, press Enter. Show the focus ring and the turn change. |
| 0:51 | Mobile | Cut to the 390px view; show the full-width New Game and the scoreboard. |
| 0:56 | Repo | End on the README or the live URL. |
