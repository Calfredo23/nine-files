# SECRETS

No secrets are used by this project.

- The app is fully client-side. There is no API key, token, connection string, or
  server credential in the code, the build, or the repo.
- Vercel deployment authentication is held by the owner in the CLI session. No value
  is read, printed, or committed by the agent.
- `.env*` is ignored by the project `.gitignore` and was never created.
